# portal-educaional

## Sobre o projeto
Site educativo com conteúdos sobre resistores e Lei de Ohm.

## Tecnologias
- HTML
- CSS
- JavaScript

## Como executar
1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html`.
3. Clique com o botão direito e selecione **Open with Live Server**.
4. O site será aberto no navegador.

## Estrutura do projeto
- `index.html`: estrutura do site.
- `css/style.css`: aparência do site.
- `js/script.js`: funcionalidades.
- `img/`: imagens e logo.

## Funcionalidades
- Barra lateral para conteúdos.
- Pesquisa de conteúdo.
- Botão de login.
- Rodapé com contatos e mapa do site.
